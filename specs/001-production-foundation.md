# Spec 001：skill.zaowuyun.com 生产基础版

## 目标

在不影响服务器现有业务的前提下，建立一个可验证、可回滚、默认不泄露候选数据的可信技能市场入口。

## 用户价值

访问者能理解造物云为什么不是简单转载技能，而是在发布来源清晰、证据当前、可以被治理的能力。目录尚无真实 Release 时，页面应诚实展示空状态，而不是填充虚假数据。

## 范围

### 包含

- 中文市场首页；
- 可信准入六道门；
- 公共目录读取与空状态；
- 健康与就绪接口；
- 安全响应头和静态路径越界防护；
- CI、systemd、Nginx 和版本目录发布；
- HTTP Host 头验收。

### 不包含

- 生产数据库写入；
- 用户账户、支付、评论；
- 第三方技能执行；
- 未完成终审的候选展示；
- DNS 控制台修改与 HTTPS 证书签发。

## 验收标准

1. `npm test` 与 `npm run check` 全部通过。
2. `/healthz` 返回 200；`/readyz` 能读取并验证目录固定结构。
3. 仅 GET/HEAD 可读取公开内容，其他方法返回 405。
4. 路径穿越、目录外文件和非固定目录结构失败关闭。
5. 服务只监听回环地址；公网只经 Nginx 进入。
6. 发布位于版本目录，`current` 为可原子恢复的软链接。
7. 使用 `Host: skill.zaowuyun.com` 访问目标服务器返回新站。
8. DNS 未指向目标服务器时不得尝试签发证书。
9. systemd 沙箱必须与 Node/V8 兼容；禁止使用会阻断 JIT 可执行内存的 `MemoryDenyWriteExecute`。

## 回滚

记录发布前 `current` 指向；若健康检查、Nginx 检查或 Host 验收失败，将 `current` 恢复至旧版本，重启服务并复测。首次发布没有旧版本时，停用服务并移除本次 Nginx enabled 链接。
